# bmol-designs

Framework-agnostic design tokens, metrics, and styling primitives for modern Apple-style and Liquid Glass interfaces.

Zero UI-framework lock-in: designed to be shared across Iced, Qt, Slint, and other native GUI runtimes.

## Features

- **Corner Models**: Apple continuous squircle curvature presets.
- **Glass Roles & Materials**: Optical parameters for Sidebars, Toolbars, and Floating controls.
- **Semantic Color Palettes**: Light and dark mode tokens for macOS-inspired split views.
- **Typography & Metrics**: Text size scales, font family resolution, and traffic lights layout constants.
